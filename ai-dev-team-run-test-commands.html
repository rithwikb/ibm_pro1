2 · Run the Main Pipeline

run
Run the full end-to-end pipeline
Requires BOB_API_KEY + WATSONX_PROJECT_ID in .env. Runs all 7 agents in sequence.
python orchestration/pipeline.py --request "Add rate limiting to the login endpoint" --repo sample_repo/flaskbb --task-id task_001

3 · Scan Repo & Auto-Fix Bugs

run
Step 1 — Scan FlaskBB for flake8 errors
Runs flake8, saves results to dashboard/bugs.json.
python orchestration/scan.py --source sample_repo/flaskbb/flaskbb
run
Step 2 — Run pipeline on selected bugs
After selecting bugs in the dashboard, this runs the pipeline on each one.
python orchestration/scan.py --source sample_repo/flaskbb/flaskbb --run-selected
run
Apply approved diffs to disk + verify with flake8
Dry-run first to preview, then run without --dry-run to apply.
python orchestration/apply_fixes.py --repo sample_repo/flaskbb --dry-run python orchestration/apply_fixes.py --repo sample_repo/flaskbb

Quick Reference — What Needs .env Credentials

note
Commands that work WITHOUT BOB_API_KEY
All tests, dashboard UI, manager agent, bug scanner (flake8 only), help flags.
python -m pytest --tb=short -q python -m streamlit run dashboard/app.py python orchestration/scan.py --source sample_repo/flaskbb/flaskbb python agents/manager_agent/manager.py --task pipeline_output.json
needs .env
Commands that REQUIRE BOB_API_KEY + WATSONX_PROJECT_ID
Any command that calls the IBM watsonx LLM.
python orchestration/pipeline.py --request "..." --repo sample_repo/flaskbb python orchestration/build.py --description "..." --name my_app python orchestration/scan.py --source sample_repo/flaskbb/flaskbb --run-selected python agents/pm_agent/pm_agent.py --request "..."

.env must contain:
BOB_API_KEY=your_ibm_cloud_api_key
WATSONX_PROJECT_ID=your_project_id
WATSONX_BASE_URL=https://us-south.ml.cloud.ibm.com  (optional)
WATSONX_MODEL_ID=ibm/granite-4-h-small  (optional)
